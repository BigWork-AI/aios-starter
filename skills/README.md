# Skills

The jobs this brain has been taught, in your words. Each one is a Claude skill in
`.claude/skills/<name>/SKILL.md`: in a new chat, type / to see them, or just ask for one in plain
words. Your voice is skill one; every skill that drafts reads it first. Teach a new one by saying
"teach you something" or "I wish I didn't have to do X".
