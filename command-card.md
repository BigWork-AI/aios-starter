# Command card

Six commands. Questions need no command: ask the brain anything in plain words, in any window.

| Type | What happens |
|---|---|
| `/start` | The kickoff interview. Run once; run again to finish skipped parts. |
| `/meeting` | File a meeting that was not recorded. Recorded meetings file themselves. |
| `/learned` | Before closing a chat: everything worth keeping gets written to the right place. |
| `/client` | Add a new client or prospect, or update where one stands. |
| `/week` | Friday review: what moved, what is overdue, what to do next week. |
| `/teach` | Teach the brain a task you hate, in your words. It becomes a command. |

Saving is automatic when a session ends. `/save` does it on demand if you want to be sure.
